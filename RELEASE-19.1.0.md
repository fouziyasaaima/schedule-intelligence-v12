# Schedule Intelligence v19.1.0 — Interactive Intelligence & Theme Hardening

## Included
- Explicit selected-task state in the Schedule task grid with keyboard accessibility and high-visibility focus styling.
- MAC latest-answer dock directly above the Ask MAC composer so the latest response is visible without scrolling.
- MAC working state remains visible above the composer while a request is being processed.
- Expanded MAC light-mode surface parity, including Materiality, Autopilot, evidence, conversation, composer, and module MAC surfaces.
- Light-mode parity improvements for the major Gantt, Network, Pulse, Intelligence, Connector and navigation surfaces.
- Connector Studio search, status filtering, sorting, and result count for large connector inventories.
- Version bumped to 19.1.0 and Docker default version updated.
- Existing Pulse and Intelligence drill-down behavior retained and visually integrated with the new theme contract.

## Architecture principle
MAC remains an optional intelligence/action layer. Deterministic SI scheduling, validation, resource analysis and export must continue when MAC is unavailable.
